# Правила монтажа (пожелания автора)

- Звуковые эффекты — заметно тише, чем в роликах про Лало и Начо: голос и вставки главнее.
- Без синтетических «вжухов» (whoosh), нарастаний (riser), глитчей и прочих «нейронных» переходов. Склейки — чистые;
  из шумов оставлять только естественные предметные звуки (бумага, щелчок фотоаппарата, штамп, ручка) и негромко.
- Мат во вставках не использовать.
- Ударения в тексте для голоса — заглавная гласная.
- Превью: большое слово прямо за героем, фото автора без приближения.
- Каждый план держится на экране минимум 2 с.
- Сценарий сверять с сериями досконально до озвучки.
