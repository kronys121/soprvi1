# Досье: Хэнк Шрейдер — части ролика

Полный ролик (20:47, 1080p60) порезан на 23 частей примерно по 55 секунд, без перекодирования.

## Как склеить
Нужен ffmpeg (Windows: https://www.gyan.dev/ffmpeg/builds/ — распаковать и добавить в PATH; macOS: `brew install ffmpeg`).

- **Windows:** скачать папку целиком и дважды кликнуть `merge.bat`
- **macOS / Linux:** `./merge.sh`

Получится `hank_full.mp4` рядом с частями. Порядок23 частей задан в `list.txt`.
