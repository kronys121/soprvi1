# Досье: Сол Гудман — части ролика

Полный ролик (21:20, 1080p60) порезан на 24 частей примерно по 55 секунд, без перекодирования.

## Как склеить
Нужен ffmpeg (Windows: https://www.gyan.dev/ffmpeg/builds/ — распаковать и добавить в PATH; macOS: `brew install ffmpeg`).

- **Windows:** скачать папку целиком и дважды кликнуть `merge.bat`
- **macOS / Linux:** `./merge.sh`

Получится `saul_full.mp4` рядом с частями. Порядок частей задан в `list.txt`.
